# Calculadora-python[cite: 10]

Versão inicial de uma calculadora simples em Python que realiza soma, diferença, multiplicação e divisão inteira a partir de dois números informados no terminal[cite: 2, 7, 9, 10].

## Como executar

1. Certifique-se de ter o **Python 3** instalado na máquina.
2. Clone o repositório:
   ```bash
   git clone [https://github.com/ruanoliveiraro2-cpu/Calculadora-python.git](https://github.com/ruanoliveiraro2-cpu/Calculadora-python.git)

   cd Calculadora-python

   python3 Calculadora.py
